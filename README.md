# RedesNeuronales

Proyecto de aprendizaje automático enfocado en la implementación y estudio de redes neuronales artificiales.

## 🎯 Características

- Implementación modular de redes neuronales
- Gestión organizada de datos y modelos
- Utilidades personalizadas para entrenamiento
- Enfoque educativo y práctico

## 🚀 Tecnologías Utilizadas

- **Python 100%** - Implementación completa en Python

## 📁 Estructura del Proyecto

```
RedesNeuronales/
├── main.py                    # Punto de entrada principal
├── data/                      # Conjunto de datos
│   └── [archivos de datos]
├── models/                    # Modelos de redes neuronales
│   └── [implementaciones]
├── utils/                     # Utilidades y helpers
│   └── [funciones auxiliares]
└── .idea/                     # Configuración del IDE
```

## 💻 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/SantiagoDelacruz-SE/RedesNeuronales.git
```

2. Accede al directorio:
```bash
cd RedesNeuronales
```

3. Instala las dependencias:
```bash
pip install -r requirements.txt
```

4. Ejecuta el programa:
```bash
python main.py
```

## 🧠 Conceptos Implementados

- Arquitectura de redes neuronales
- Procesamiento de datos de entrenamiento
- Entrenamiento y validación de modelos
- Guardado y carga de modelos entrenados

## 📊 Uso

El proyecto está diseñado para experimentar con diferentes arquitecturas de redes neuronales y técnicas de aprendizaje automático.
